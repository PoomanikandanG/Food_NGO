# FoodBridge

FoodBridge is a polished, responsive one-page concept for a social-impact platform connecting surplus food donors with NGOs and communities in need.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

The production output is written to `dist/` and is ready for Vercel. Vercel will detect Vite automatically; the build command is `npm run build` and the output directory is `dist`.

## Notes

- The “Find a sample match” interaction is intentionally frontend-only. It does not submit donations, contact NGOs, or represent a live operational match.
- Metrics and community stories are explicitly illustrative/demo content.
- Photography is loaded from Unsplash image URLs and credited in the footer.
- Contact email addresses use the `.example` placeholder domain because no operational contact details were supplied.
